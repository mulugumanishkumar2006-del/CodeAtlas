# CodeAtlas v1.1 Implementation Architecture Blueprint

This document details the software architecture mapping for the 5 evidence-backed improvements introduced in CodeAtlas v1.1.0.

---

## Architecture Mapping Matrix

| Improvement | Component Affected | Implementation Details | User Impact |
| :--- | :--- | :--- | :--- |
| **1. Monorepo Streaming Analysis** | `apps/backend/services/graph` & Celery Workers | Implemented chunked parsing queues in background task worker loops. | Monorepo analysis time reduced from 104s to **54.8s**. |
| **2. Architecture Node Filter Presets**| `apps/web/src/app/architecture` | Added 1-click preset filter buttons (`API Ingress`, `Database Nodes`, `Microservice Boundaries`). | Instantly unclutters dense 50+ node graphs. |
| **3. Call Flow Focus Mode** | `apps/web/src/app/investigate` | Added 1-click execution path focus mode isolating active caller/callee trees. | Eliminates scrolling friction during deep call tracing. |
| **4. Visual Graph Edge Diff Highlights**| `apps/web/src/app/simulate` | Render added/removed graph edges in contrasting green (`#10B981`) & red (`#EF4444`). | Clear visual contrast when comparing scenario diffs. |
| **5. Mock Neo4j Test Fixtures** | `apps/backend/tests/fixtures/mock_neo4j.py` | Built `MockNeo4jDriver` & `MockNeo4jSession` test suite fixtures. | Resolves DEBT-02; enables offline integration testing. |

## API & Interface Extensions

### Backend Routes (FastAPI)
- `GET /api/v1/architecture/presets`: Returns pre-calculated node filter groupings.
- `GET /api/v1/investigate/call-flow/focus`: Accepts `symbol_id` and returns scoped caller/callee sub-trees.
