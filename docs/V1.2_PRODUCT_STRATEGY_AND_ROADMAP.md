# CodeAtlas v1.2 Product Strategy, Architecture & Roadmap

This document establishes the official product strategy, technical architecture, and implementation roadmap for **CodeAtlas v1.2**.

---

## 1. Product North Star & Core Value Proposition

> [!IMPORTANT]
> **CODEATLAS PRODUCT NORTH STAR**
> **"Help developers understand the consequences of changing software before they change it."**

CodeAtlas owns the **Change Impact Prediction & Architecture Intelligence** space across multi-repository enterprise codebases.

---

## 2. Core Value Loop Architecture

```
UNDERSTAND (Multi-Repo Architecture & Dependency Graph)
       ↓
INVESTIGATE (Root Cause, Call Flows & Boundary Drift Alerts)
       ↓
SIMULATE (Change Impact Prediction Engine & Graph Diffs)
       ↓
DECIDE (Grounded AI CTO Advisor & Trade-off Analysis)
       ↓
IMPROVE (Level 4 Human-Authorized Autonomous Refactoring)
```

---

## 3. Data Architecture Extensions

## 4. Proposed REST API Contracts

### Endpoint 1: Predict Change Impact
- **URL**: `POST /api/v1/simulation/predict-impact`
- **Request Body**:
  ```json
  {
    "workspace_id": "ws-123",
    "target_symbol_id": "sym-456",
    "proposed_change_type": "SIGNATURE_MODIFY"
  }
  ```
- **Response**:
  ```json
  {
    "impact_score": 7.8,
    "affected_services_count": 3,
    "affected_files": ["services/user_service.py", "api/routes.py"],
    "blast_radius_risk": "HIGH"
  }
  ```

## 5. Implementation Roadmap (`NOW` / `NEXT` / `LATER` / `NOT NOW`)

### NOW (Phase A — Immediate Scope)
- **Initiative 1**: Change Impact Prediction Engine backend logic & API contract.
- **Initiative 2**: Multi-Repo Cross Dependency Graph visualizer.

### NEXT (Phase B — Subsequent Scope)
- **Initiative 3**: Architecture Boundary Drift Alerts & Slack/Webhook notifications.

### LATER (Phase C — Future Scope)
- Temporal Codebase Evolution View & Shared Investigation Annotations.

### NOT NOW (Explicitly Rejected Scope)
- Fully Autonomous AI Execution without Level 4 Human Approval.
