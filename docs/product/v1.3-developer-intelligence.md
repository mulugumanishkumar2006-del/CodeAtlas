# CodeAtlas v1.3 — Core Developer Intelligence Specification

## 1. Executive Summary

**CodeAtlas v1.3** transforms repository understanding into **Engineering Decision Intelligence**. When faced with complex architectural questions ("Why is this service slow?", "What will break if I change this?"), CodeAtlas guides developers through a grounded, explainable decision loop:

$$QUESTION \rightarrow INVESTIGATE \rightarrow EVIDENCE \rightarrow HYPOTHESIS \rightarrow FINDINGS \rightarrow OPTIONS \rightarrow SIMULATE \rightarrow RECOMMEND \rightarrow DECIDE \rightarrow IMPLEMENT \rightarrow VALIDATE \rightarrow LEARN$$

---

## 2. Architecture & Data Model

### A. Multi-Hypothesis Management
- **Status Categories**: `OPEN`, `SUPPORTED`, `REJECTED`, `UNKNOWN`.
- **Validation**: Requires automated trace, test, or log audit verification before confirming status.

### B. Structured Findings Pipeline
Converts evidence into typed signals:
- `FACT`: Direct AST or call graph node evidence.
- `RISK`: Blast radius impact warnings.
- `DEPENDENCY`: Cross-module edge coupling.
- `ARCHITECTURE_ISSUE`: Boundary violation or high coupling score ($> 0.75$).
- `PERFORMANCE_SIGNAL`: Latency trace bottleneck.
- `SECURITY_SIGNAL`: Secret scan or RBAC boundary breach.
- `HISTORICAL_SIGNAL`: Regression pattern from Code Time Machine history.

### C. Engineering Options & Simulation Integration
Generates multiple candidate approaches (Option A vs B vs C) and invokes the **v1.2 Simulation Studio Engine** to project virtual graph diffs and risk deltas ($Current \rightarrow Simulated$).

---

## 3. Explainable Option Scoring Formula

$$\text{Option Score} = \left( 0.30 \cdot \text{User Value} + 0.25 \cdot \text{Modularity} + 0.20 \cdot \text{Fidelity} - 0.15 \cdot \text{Risk Delta} - 0.10 \cdot \text{Complexity} \right) \cdot 10.0$$

---

## 4. Decision Records & History

- Immutable decision records stored with owner, rationale, tradeoffs, and rejected alternatives.
- Non-destructive implementation plans generating file/API/DB/test checklists.
- Plan vs Actual Git diff comparison to detect unexpected dependencies or architectural drift post-implementation.
