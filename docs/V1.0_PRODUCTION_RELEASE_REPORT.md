## Known Platform Limitations in v1.0.0
1. **Supported Languages**: Primary deep-parsing support for JavaScript, TypeScript, Python, Go, and Java. Other languages default to file and dependency-level indexing.
2. **Analysis Time on Monorepos**: Repositories exceeding 5,000 files require 1–2 minutes for full graph indexing.
3. **External LLM Outages**: In the event of external LLM provider downtime, AI CTO chat switches to local Knowledge Graph fallback mode.
