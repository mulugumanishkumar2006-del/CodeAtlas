# CodeAtlas Enterprise Service Catalog Specification

## Service Catalog Tracking

Tracks all microservices across production and pre-production environments:
- `Service & Repository`: Service name and source repository mapping.
- `Owner & Environment`: Owner team and active cluster environments.
- `APIs & Databases`: Exposed HTTP/gRPC interfaces and connected database clusters.
- `SLOs & Incidents`: Target availability SLO (e.g. 99.99%) and active incident correlation.
