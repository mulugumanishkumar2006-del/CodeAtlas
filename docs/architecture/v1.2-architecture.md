# CodeAtlas v1.2 Target Architecture & Data Foundation

This document defines the target data models, knowledge graph Cypher schemas, evidence standards, and API contracts for CodeAtlas v1.2.

---

## 1. Domain & Evidence Model Specification

Every intelligence output in CodeAtlas v1.2 contains 5 evidence attributes:

```json
{
  "what": "Signature modification on AuthService.authenticate_user()",
  "where": "services/auth_service.py:L45-L62",
  "why": "Alters parameter order required by 3 calling microservices",
  "source": "git://github.com/codeatlas/enterprise-api.git",
  "confidence": 0.96
}
```

---

## 2. Extended Knowledge Graph Cypher Model

```cypher
// Extended v1.2 Cypher Graph Schema
(:Service {id: $service_id, name: $name, org_id: $org_id})
  -[:DEPENDS_ON {type: "HTTP_REST", latency_ms: 12}]-> (:Service)
  -[:EMITS_EVENT {topic: "order.created"}]-> (:MessageQueue)
  -[:MUTATES {table: "users"}]-> (:Database)
  -[:CALLS {frequency: "HIGH"}]-> (:Function)
```

## 3. Proposed v1.2 API Contracts

### Predict Change Impact Endpoint
- **URL**: `POST /api/v1/simulation/predict-impact`
- **Request**:
  ```json
  {
    "workspace_id": "ws-prod-01",
    "target_symbol_id": "sym-8492",
    "proposed_change_type": "SIGNATURE_MODIFY"
  }
  ```
- **Response**:
  ```json
  {
    "status": "SUCCESS",
    "impact_score": 7.8,
    "affected_services_count": 3,
    "affected_files": ["services/user_service.py", "api/routes.py"],
    "blast_radius_risk": "HIGH",
    "evidence": {
      "confidence": 0.96,
      "source": "services/auth_service.py"
    }
  }
  ```
