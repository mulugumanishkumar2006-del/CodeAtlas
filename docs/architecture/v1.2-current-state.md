# CodeAtlas v1.2 Current Architecture Audit

This document maps the current production architecture of CodeAtlas v1.1.0 prior to v1.2 foundation extensions.

## Architectural Gap Analysis for v1.2

| Architectural Dimension | Current v1.1 Capability | Required v1.2 Foundation | Gap Resolution Strategy |
| :--- | :--- | :--- | :--- |
| **Change Impact Tracing** | Manual graph diffs | Automated Predictive Blast Radius Calculation | Implement `impact_analyzer.py` service layer |
| **Knowledge Graph Schema** | Basic `:DEPENDS_ON` edges | Rich `:EMITS_EVENT`, `:MUTATES`, `:CALLS` relationships | Extend Cypher graph builder schemas |
| **Database Connection Pooling**| Direct SQLAlchemy pool (20 conn) | PgBouncer transaction connection pooler (100 conn) | Configure PgBouncer in staging/production |
| **Context Evidence Pipeline** | Raw RAG retrieval | Structured Evidence Pipeline (What/Where/Why/Source/Confidence) | Standardize AI context payload schemas |
