# CodeAtlas Authorization & RBAC Specification

## Configurable Tenant Roles

- **OWNER**: Full administrative control, billing, member management, and workspace deletion.
- **ADMIN**: Organization configuration, policy rules, agent approvals, and integration management.
- **ENGINEER**: Repository connection, code analysis, simulation runs, and pull request reviews.
- **VIEWER**: Read-only access to architecture graphs, reports, and dashboards.
- **AUDITOR**: Access to compliance logs, security checks, and audit trails.
