# Strategic Objectives & Constraints Model

Supports organization-defined strategic objective categories:
- `REDUCE_ARCHITECTURE_RISK`
- `IMPROVE_RELIABILITY`
- `REDUCE_TECHNICAL_DEBT`
- `ACCELERATE_DELIVERY`
- `SIMPLIFY_ARCHITECTURE`
- `REDUCE_DEPENDENCY_CONCENTRATION`
- `MODERNIZE_TECHNOLOGY`
- `IMPROVE_SECURITY_POSTURE`
