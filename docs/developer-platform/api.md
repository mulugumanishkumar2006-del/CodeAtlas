# CodeAtlas v2.2 Developer Platform — Public API Specification

## Stable REST API Endpoints

- `/api/v1/auth`: Authentication and session management
- `/api/v1/organizations`: Enterprise organization hierarchy
- `/api/v1/workspaces`: Multi-workspace isolation boundaries
- `/api/v1/teams`: Engineering ownership mapping
- `/api/v1/repositories`: Code repository catalog and indexing
- `/api/v1/architecture`: Software architecture intelligence
- `/api/v1/graph`: Software Knowledge Graph queries
- `/api/v1/search`: Permission-aware code and architecture search
- `/api/v1/knowledge`: Enterprise Knowledge Fabric & Freshness
- `/api/v1/investigations`: Autonomous root cause investigations
- `/api/v1/simulations`: Digital twin impact simulations
- `/api/v1/agents`: Agent execution and governance
- `/api/v1/deployments`: Control plane deployment guardrails
- `/api/v1/reports`: Enterprise executive scorecards and reports
- `/api/v1/events`: Normalized event bus stream
