# Specialized Autonomous Agents & Multi-Agent Orchestration

## Agent Roles
- **Investigator**: Identifies root causes and gathers codebase evidence.
- **Architect**: Generates architecture plans and checks boundary constraints.
- **Coder**: Modifies files cleanly inside isolated worktree sandboxes.
- **Tester**: Executes test suites and validates build outputs.
- **Security Reviewer**: Audits diffs for secret leakage and dangerous commands.
- **SRE & Release Agent**: Manages controlled execution and post-execution verification.
