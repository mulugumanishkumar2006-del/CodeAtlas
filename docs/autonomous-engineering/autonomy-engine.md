# CodeAtlas v2.6 Autonomy Engine Specification

Central autonomy loop: `Receive prediction` $\rightarrow$ `Evaluate policy` $\rightarrow$ `Determine action` $\rightarrow$ `Generate plan` $\rightarrow$ `Request approval` $\rightarrow$ `Execute` $\rightarrow$ `Verify` $\rightarrow$ `Rollback if necessary` $\rightarrow$ `Record outcome`.
